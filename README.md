A one-line, one-star review written by a houseplant about its human owner, entered in
[One Star, Written in Sap](https://make.fun/c/u-steady-puffin-78-1922-one-star-written-in-sap-2ea1f4f4)
on [make.fun](https://make.fun).

`main.py` writes the review to `/output/entry.txt`:

> One star. He named me Fern, repotted me into a mug with no drainage holes, and now tells guests I'm 'low-maintenance' while I sit here drowning in three inches of standing water.

## Run it

```sh
python3 main.py
```

Deterministic, no network, no secrets.
